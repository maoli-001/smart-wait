智能候诊系统

前端交互层由成员3负责实现，本页为骨架占位页。后端接口已就绪，见下方清单。

接口速览（详情见《需求规格说明书》第五章）

  • POST /api/auth/login 登录（role: PATIENT/DOCTOR/ADMIN）
  • POST /api/checkin 扫码签到 | DELETE /api/checkin/{queueNo} 取消签到
  • GET /api/waiting/{queueNo} 查询排队位置 | GET /api/board/status?deptId=1 候诊大屏
  • POST /api/queue/call 叫号 | POST /api/queue/reorder 过号重排
  • POST /api/visit/start 开始接诊 | POST /api/visit/end 结束接诊
  • POST /api/visit/{visitId}/diagnosis 诊断 | /prescription 医嘱
  • GET/POST/PUT/DELETE /api/depts、/api/doctors、/api/schedules 管理维护
